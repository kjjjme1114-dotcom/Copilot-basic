Copilot 업무 활용 기본교육 실습 교재

여러분은 안랩샘아카데미 "Copilot 업무 활용 기본교육"의 교육 운영 담당자입니다. 다음 기수 교육을 준비하면서 Copilot으로 자료를 정리하고, 커리큘럼을 문서로 만들고, 메일과 일정을 처리하고, 수강생 문의 에이전트까지 만들어 봅니다. 예시 프롬프트와 예시 답안은 모두 "참고"에 접어 두었습니다. 먼저 직접 프롬프트를 써 보고, 막힐 때만 펼쳐 보세요.

실습 준비 사항

  1. Microsoft 365 Copilot 라이선스가 할당된 실습 계정으로 로그인합니다. 노트북, Outlook Copilot, 메일과 일정 기반 질문은 라이선스가 있어야 쓸 수 있습니다.
  2. 브라우저는 Microsoft Edge나 Chrome 최신 버전을 권장합니다. Outlook은 새 Outlook이나 웹 Outlook을 사용하세요.
  3. 실습 7(Copilot Studio)은 계정에 Copilot Studio 권한이 있어야 합니다. 권한이 없으면 실습 7의 "간편 방법(에이전트 빌더)"으로 진행합니다.
  4. 아래 샘플 자료 3종을 각각 Word 문서로 저장해서 본인 OneDrive > "Copilot실습" 폴더에 올려 둡니다.
💡 샘플 자료의 일정, 인원, 수치, 이름은 실습용 가상 데이터입니다. Copilot 메뉴 이름과 위치는 업데이트나 조직 설정에 따라 조금씩 다를 수 있으니(예: 노트북 = 전자 필기장), 비슷한 아이콘과 메뉴를 찾아 진행하세요.

  • 프롬프트는 직접 먼저 써 봅니다. 각 실습의 "참고 ① 예시 프롬프트"는 막혔을 때만 펼칩니다.
  • 결과는 비교하고 검증합니다. "참고 ② 예시 답안"은 여러 정답 중 하나입니다. Copilot 응답은 매번 조금씩 다르게 나오며, 각주(출처)를 눌러 원문과 맞는지 꼭 확인합니다.
  • 결과물을 이어서 씁니다. 실습 1의 결과가 실습 2와 3의 재료가 되고, 실습 4~7도 같은 시나리오로 이어집니다.

실습 1. Copilot 노트북(전자 필기장)에 자료 수집·정리

Copilot 노트북은 한 프로젝트의 파일, Page, 메모를 한곳에 모아 두고 그 자료를 근거로 Copilot에게 질문할 수 있는 작업 공간입니다. 운영계획서, 사전 설문, 이전 기수 회고를 모아서 이번 기수에서 개선할 점을 정리해 봅니다.

실습 절차

  1. m365.cloud.microsoft에 접속해 왼쪽 메뉴에서 [노트북](또는 [전자 필기장])을 선택합니다.
  2. [새 노트북]을 누르고 이름을 "안랩샘 Copilot 기본교육 운영"으로 입력합니다.
  3. 오른쪽 콘텐츠 창 위쪽의 [참조 추가]를 누르고 OneDrive "Copilot실습" 폴더의 샘플 파일 3개를 선택합니다.
  4. 노트북 설정에서 지침(사용자 지정 지침)을 입력해 Copilot이 어떤 역할로, 어떤 형식으로 답할지 정합니다.
  5. 아래 미션의 결과가 나오도록 직접 프롬프트를 써서 질문합니다.
  6. 마음에 드는 응답은 노트북에 페이지로 저장하거나 메모로 남깁니다.
🎯 미션: 노트북에서 아래 네 가지를 얻어 보세요.
  • Copilot이 "교육 운영 전문가" 역할로, 첨부 자료만 근거로 답하게 하는 노트북 지침
  • 첨부 자료 3개를 각각 3줄로 요약한 결과
  • 설문과 회고를 비교해서 뽑은 이번 기수 개선 이슈 5가지 표 (이슈 / 근거 / 개선 방향)
  • 개강일(10/20) 기준 D-14, D-7, D-1 준비 체크리스트
개선 이슈 표는 실습 2와 3에서 다시 씁니다.

실습 2. Copilot 프롬프트 코치 에이전트로 질문 개선

Prompt Coach(프롬프트 코치)는 Microsoft가 기본 제공하는 에이전트입니다. 내가 쓴 프롬프트를 진단하고 더 좋은 프롬프트로 고쳐 줍니다. 좋은 프롬프트의 4요소인 목표(Goal), 맥락(Context), 출처(Source), 기대 결과(Expectation)를 기준으로 피드백을 줍니다.

요소의미생각해 볼 질문
목표 (Goal)무엇을 얻고 싶은가어떤 결과물이 필요한가?
맥락 (Context)왜, 누구를 위해, 어떤 상황인가수강생은 누구이고, 어떤 문제가 있었나?
출처 (Source)어떤 자료를 근거로 할 것인가어떤 파일을 참고해야 하나?
기대 결과 (Expectation)형식, 분량, 어조표로? 회차별로? 어떤 항목이 필요한가?

실습 절차

  1. Microsoft 365 Copilot 채팅 왼쪽의 [에이전트] 영역에서 [모든 에이전트](또는 에이전트 스토어)를 엽니다.
  2. 검색창에 "Prompt Coach"를 입력하고 [추가]를 누릅니다.
  3. 왼쪽 에이전트 목록에서 Prompt Coach를 선택해 대화를 시작합니다.
  4. 아래 "개선할 프롬프트"를 코치에게 보내고 피드백을 받습니다.
  5. 코치의 질문에 답하면서 프롬프트를 완성합니다. 실습 1의 자료 내용을 맥락으로 활용하세요.
  6. 완성한 프롬프트를 일반 Copilot 채팅(또는 실습 1 노트북)에 넣고 개선 전과 후의 결과를 비교합니다.
🎯 미션: 아래 프롬프트를 코치와 함께 개선해 보세요.
  • 개선할 프롬프트: "Copilot 교육 커리큘럼 만들어줘"
  • 4요소가 모두 들어간 개선 프롬프트를 완성합니다.
  • 다음 교육에서도 쓸 수 있는 빈칸형 프롬프트 템플릿으로 바꿔 달라고 요청합니다.
  • 개선 전과 후 응답의 차이를 한 줄로 적어 봅니다.
완성한 프롬프트는 실습 3에서 그대로 사용합니다.

Prompt Coach 피드백 예시

좋은 출발입니다! 다만 지금 프롬프트에는 목표만 있고 나머지 요소가 빠져 있어서 일반적인 답변이 나올 가능성이 큽니다.

• 맥락: 수강생이 누구인지, 교육 시간과 회차, 수강생의 수준을 알려 주세요.
• 출처: 참고할 파일(설문, 회고)을 지정하면 근거 있는 결과가 나옵니다.

실습 3. Copilot 응답을 Pages로 전환 및 수정

Copilot Pages는 채팅 응답을 편집하고 공유할 수 있는 문서로 바꿔 줍니다. Page에서 직접 고치고, 원하는 부분만 Copilot에게 다시 쓰게 하고, 강사진과 함께 편집할 수 있습니다.

실습 절차

  1. Copilot 채팅(또는 실습 1 노트북)에 실습 2에서 완성한 프롬프트를 입력합니다.
  2. 응답 아래의 [Pages에서 편집](연필 아이콘)을 누르면 오른쪽에 Page가 열립니다.
  3. Page 제목을 "안랩샘 Copilot 기본교육 커리큘럼(안)"으로 바꿉니다.
  4. 고치고 싶은 부분을 드래그로 선택한 뒤 Page 안의 Copilot 입력창(Ask Copilot)에 수정 요청을 입력합니다.
  5. 채팅에서 추가로 받은 응답(예: 보고용 요약)을 같은 Page에 추가합니다.
  6. 오른쪽 위 [공유]로 링크를 복사해 옆 사람(강사진 역할)에게 보내고 공동 편집을 요청합니다.
🎯 미션: 커리큘럼 Page를 아래처럼 고쳐 보세요.
  • 1회차 시작 전에 30분 사전 접속·로그인 점검 시간(18:30~19:00)을 추가합니다.
  • 표에 준비물과 보조강사 역할 열을 추가합니다.
  • 운영사무국에 보고할 수 있게 5줄 요약과 운영 목표(KPI) 표를 Page 맨 위에 넣습니다.
  • 옆 사람에게 공유 링크를 보내 한 줄 의견을 받습니다.

실습 4. Outlook에서 메일 초안 작성

실습 절차

  1. Outlook에서 [새 메일]을 누릅니다.

방법 A. Copilot 채팅으로 메일함 전체 요약

  1. Microsoft 365 Copilot 채팅을 열고 업무(Work) 모드인지 확인합니다.

방법 B. Outlook에서 메일 스레드 요약

  1. Outlook에서 긴 메일 스레드(예: 강사 교안 검토 메일)를 엽니다.
  2. 메일 위쪽의 [Copilot으로 요약](또는 요약) 버튼을 누릅니다.
  3. 바로 답장이 필요하면 실습 4처럼 [Copilot으로 초안 작성]으로 이어서 답장을 씁니다.

실습 7. Copilot Studio로 에이전트 만들기

이전 기수에는 "출석 인정되나요?", "미션은 어디에 내요?" 같은 같은 문의가 주 40건 넘게 들어왔습니다. 수강생의 반복 문의에 대신 답하는 "안랩샘 Copilot 교육 도우미" 에이전트를 만들어 Teams에 배포해 봅니다.

실습 절차

  1. copilotstudio.microsoft.com에 접속해 오른쪽 위에서 환경이 실습용 환경인지 확인합니다.
  2. 왼쪽 메뉴의 [만들기] → [새 에이전트]를 선택합니다.
  3. 대화창에 만들고 싶은 에이전트를 직접 설명합니다. Copilot이 질문하면 답하면서 이름, 설명, 지침을 채웁니다.
  4. [구성] 탭으로 가서 이름, 설명, 지침을 확인하고 다듬습니다.
  5. [지식 추가]에서 운영계획서, 실습 3의 커리큘럼 Page(또는 Word로 저장한 파일), 수강생 FAQ 문서를 연결합니다.
  6. 교육 자료로만 답하게 하려면 웹 검색(일반 지식) 사용을 끕니다.
  7. 수강생이 바로 눌러 볼 제안 프롬프트(시작 질문)를 3~4개 등록합니다.
  8. 오른쪽 [테스트] 창에서 질문해 보고, 답이 틀리면 지침이나 지식을 고칩니다.
  9. 오른쪽 위 [게시]를 누른 뒤 [채널] → [Teams 및 Microsoft 365 Copilot]을 추가하고 공유 대상(수강생 그룹)을 지정합니다.

증상원인해결 방법
노트북·Pages 메뉴가 보이지 않음라이선스 미할당 또는 기능 순차 배포 중실습 계정에 Microsoft 365 Copilot 라이선스가 있는지 운영진에게 확인 요청
노트북이 첨부 파일을 무시하고 답함참조 파일 인덱싱 전이거나 지침 부족잠시 뒤 다시 시도하고, 지침에 "첨부 자료만 근거로" 문구 넣기
Prompt Coach를 찾을 수 없음에이전트 미추가 또는 조직 정책[모든 에이전트]에서 검색해 추가, 없으면 운영진에게 문의
메일 요약에 일부 메일이 빠짐검색 범위 한계, 폴더·권한 차이기간, 보낸 사람, 키워드를 좁혀 다시 질문
동료 일정이 확인되지 않음일정 공유 권한 제한일정 도우미로 바쁨/한가함 확인, 또는 후보 시간을 메일로 문의
Copilot Studio에서 게시가 안 됨환경, 라이선스, 관리자 승인 필요관리자에게 Teams 게시 승인 요청, 또는 에이전트 빌더로 진행
